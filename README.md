FM TOWNS - Playground
=====================

Based on code from memtest86 FM : https://github.com/mcDomDom/memtest_FM

This is just stripped down so i can eventually make games for it and discover the hardware.
This doesn't rely on TOWNES OS or even MS-DOS.
This is made for floppy disks but in theory this can be done for CD-ROMs and even IC Memory cards.

IC Memory card : http://ysflight.in.coocan.jp/FM/towns/icm/e.html
CD-ROM : https://duriansoftware.com/joe/how-the-fm-towns-boots-from-cd-rom

The fact that you can make a game/app for the Marty that could run off an IC Memory card is nice
as most FM TOWNS Marty have failing drives or already have ODEs like DOCBROWN or THE THING.
